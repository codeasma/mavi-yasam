# Mavi Yaşam Villaları: website

Static bilingual (TR/EN) website for a villa compound. Plain HTML, CSS and JavaScript, no build step.

- `index.html`: page content (Turkish and English side by side)
- `css/style.css`: design
- `js/main.js`: language switch, floor-plan tabs, lightbox, contact links, analytics. **Edit `CONFIG` at the top.**
- `img/`: optimized project images

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.

## Deploy
Hosted with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
